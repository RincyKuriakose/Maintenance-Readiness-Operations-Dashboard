# Maintenance Readiness and Operations Dashboard

## Project Overview

This project analyzes synthetic equipment, maintenance, repair-cost, and downtime data using Excel and Power BI.

The dashboard was created to monitor equipment readiness, identify unavailable assets, compare maintenance costs, and evaluate downtime patterns across company equipment.

## Project Objectives

- Track operational, unavailable, and under-maintenance equipment
- Analyze maintenance cost by asset
- Measure downtime hours by asset
- Identify equipment with the highest repair cost and downtime
- Build an interactive Power BI dashboard for operational decision-making

## Tools Used

- Microsoft Excel
- Power BI Desktop
- Power Query
- Data visualization
- GitHub

## Dataset

The project contains three related Excel tables:

- Equipment
- Maintenance
- Downtime

The dataset includes:

- 12 equipment assets
- 15 maintenance records
- 12 downtime records

All data is synthetic and was created for demonstration purposes.

## Dashboard Metrics

- Total Equipment: 12
- Operational Equipment: 7
- Under Maintenance: 3
- Unavailable Equipment: 2

## Key Findings

- 58.33% of equipment was operational
- 25% of equipment was under maintenance
- 16.67% of equipment was unavailable
- EQ-004 had the highest maintenance cost
- EQ-004 also recorded the highest downtime at 96 hours
- EQ-012 recorded the second-highest downtime at 72 hours
